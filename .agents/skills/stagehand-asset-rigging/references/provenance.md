# Media provenance

Retain the generation prompt or source URL, author, license, license URL, decoded dimensions, color and alpha mode, creation time, and checksum when available. Source provenance is immutable even when geometry or review state changes.

External generation, uploads, paid compute, credentials, publication, and redistribution require explicit authorization. Reachability by URL does not grant redistribution rights.

Useful implementation references:

- [Meta Animated Drawings](https://github.com/facebookresearch/AnimatedDrawings)
- [Live2D Cubism documentation](https://docs.live2d.com/en/)
- [Spine runtimes guide](https://esotericsoftware.com/spine-runtimes-guide)
- [Adobe Character Animator help](https://helpx.adobe.com/adobe-character-animator/user-guide.html)

Record whether guidance came from an external reference, but do not copy third-party art or proprietary rig data into a package without suitable rights.
